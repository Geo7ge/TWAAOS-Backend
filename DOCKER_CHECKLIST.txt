🔄 COMMON OPERATIONS
───────────────────────────────────────────────────────────────────────────────

Inițiere totală (fresh start):
  docker-compose down -v
  docker-compose build --no-cache
  docker-compose up -d

Restart (fără a pierde date):
  docker-compose restart

Schimbă variabile și restart:
  1. Editează .env.docker
  2. docker-compose down
  3. docker-compose up -d

Adaugă migrație nouă:
  1. Creează: supabase/migrations/20260618_NEW.sql
  2. docker-compose restart db
  3. Sau: docker-compose down -v && docker-compose up -d

Backup database:
  docker-compose exec db pg_dump -U proiect_user -d proiect_db > backup.sql

Restore database:
  docker-compose exec -T db psql -U proiect_user -d proiect_db < backup.sql

Ștergere completă (ATENȚIE!):
  docker-compose down -v
  docker image rm backend-api
  docker image rm postgres:17-alpine
